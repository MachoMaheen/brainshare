# Licensing strategy (decision record, not legal text)

The repository has historically been MIT-licensed. Existing MIT releases remain available under those terms. Before a license migration, confirm copyright ownership and obtain legal review.

Proposed future model:

- BrainShare service/core: AGPL-3.0-or-later for future releases after the migration point.
- Protocol schemas and lightweight integration SDK: permissive license (MIT or Apache-2.0) to encourage third-party adapters.
- Optional commercial license for proprietary/OEM embedding.
- Separate BrainShare trademark policy.
- Contributor agreement appropriate for dual licensing before accepting substantial third-party contributions.

This file intentionally does **not** change the repository license by itself.
